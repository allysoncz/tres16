# Tres16

Loja virtual feita em PHP com banco MySQL.

Para rodar:

1. Copiar a pasta pro htdocs do XAMPP e ligar o Apache e o MySQL.
2. Importar o banco.sql pelo phpMyAdmin (ele cria o banco tres16 e as tabelas).
3. Conferir o usuario e a senha do MySQL no arquivo app/cons.php.
4. Abrir o index.php no navegador.
